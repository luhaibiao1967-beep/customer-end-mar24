# 用票流水表（`voucher_usage_ledger`）说明

供 **配送/财务 App**（与客户端共用 Supabase）生成报表、分店与总店对账使用。

**分店/总店报表对接（含更多 SQL 示例、权限与边界）见：`docs/分店水票订单报表-对接说明.md`。**

---

## 1. 表用途

- 记录**每次订单扣减水票**时：张数、单价（IDR）、行金额、分店快照、计价依据。
- 订单**取消并退回水票**时：写入**冲销行**（张数与金额为负），净额与 `customer_product_vouchers` 的退回一致。
- 与 `orders` 通过 **`order_id`（UUID）逻辑关联**（表上**无外键**），避免订单硬删除时阻塞；报表时 `LEFT JOIN orders` 即可。

---

## 2. 字段说明

| 列名 | 类型 | 说明 |
|------|------|------|
| `id` | `uuid` | 主键 |
| `order_id` | `uuid` | 对应 `orders.id`（逻辑引用，非 FK） |
| `customer_id` | `uuid` | 客户，FK → `customers` |
| `branch` | `text` | **写入时**客户网点快照，与当时下单一致，便于按店统计 |
| `product_id` | `uuid` | 水票商品维度，FK → `products` |
| `voucher_qty` | `integer` | 使用张数；**冲销为负数** |
| `unit_amount` | `integer` | 单张水票计价（IDR，整数） |
| `line_amount` | `integer` | `voucher_qty * unit_amount`（冲销为负） |
| `pricing_basis` | `text` | 见下表 |
| `created_at` | `timestamptz` | 写入时间 |

### `pricing_basis` 取值

| 值 | 含义 |
|----|------|
| `purchase_weighted_avg` | 根据该客户该商品在 **`voucher_purchase_requests`** 中 `status = 'confirmed'` 的 **`sum(amount_paid) / sum(qty)`** 下取整（`floor`） |
| `package_fallback` | 无确认购买记录时，取 **`voucher_packages`** 中该 `product_id` 且 `is_active = true`，按 **`sort_order` 第一条** 的 `floor(price / qty)` |
| `zero_unknown` | 无购买记录且无可用套餐时，`unit_amount = 0`（报表需自行决定是否排除或手调） |

> **说明**：单价在**扣票当时**计算，不实现 FIFO 批次；若日后要按批次精确划账，可再扩展批次表或增加字段。

---

## 3. 何时写入

| 场景 | Edge Function | 行为 |
|------|----------------|------|
| 新订单扣票 | `submit-order` | 订单与明细写入成功后，按 `product_deductions` 每个 `product_id` 插入 **正数**行 |
| 预付 + QRIS 下单扣票 | `submit-prepay-order` | **Midtrans Snap 创建成功且** `midtrans_order_id` 已保存后，再按 `product_deductions` 插入正数行（与订单保留一致） |
| 客户取消 pending 单 | `cancel-order` | 删除订单前，对该 `order_id` 已有 **`voucher_qty > 0`** 的行逐条插入 **负数冲销行**（单价与 `pricing_basis` 与原行一致） |

以下情况**不会有**流水行：

- 历史订单（迁移上线前已扣票）
- `submit-order` **编辑订单**路径当前不调整水票，也不写流水

## 4. 报表查询建议

### 4.1 按分店、按自然月汇总「用票金额」（净额）

```sql
-- 示例：按 branch、月汇总 line_amount（含冲销）
SELECT
  branch,
  date_trunc('month', created_at AT TIME ZONE 'Asia/Jakarta') AS month_jkt,
  SUM(line_amount) AS total_line_amount_idr,
  SUM(voucher_qty) AS total_vouchers
FROM voucher_usage_ledger
GROUP BY 1, 2
ORDER BY 2, 1;
```

按 **送达月** 而非写入月时，请 `JOIN orders`，用 `orders.delivered_date`（或业务约定的日期）筛选。

### 4.2 关联订单

```sql
SELECT l.*, o.status, o.delivered_date, o.delivery_date
FROM voucher_usage_ledger l
LEFT JOIN orders o ON o.id = l.order_id;
```

### 4.3 权限（RLS）

表已启用 **RLS**；默认仅 **service role** 可读写。管理端若用 **anon key**，需自行添加 `SELECT`（等）策略；或后端用 service role 代理查询。
